## Capture another failure only when needed

```powershell
cmake --build C:\repos\AnyPS5-pr639\build --target libs -- -k 0
& C:\repos\AnyPS5-pr639\profiling\rapid-capture.ps1 -Tag next-capture -MaxSeconds 260 -StopOn 'unnormalized guest sampler'
```

The capture script refuses to run alongside an existing app instance, copies built modules, enables write-watch, saves failed compute and draw-stage requests, and stops its own PID at the requested error or deadline. Logs and requests go to `D:\ps5\gt7\diagnostics-rapid\<tag>`. It does not wait for stable menu FPS. `-StopOn` matches skipped compute or draw failure text. Failure dumps cover capture/materialization exceptions, not later Vulkan execution failures such as buffer-owner errors. `APS5_TRACE_BUFFER_VIEW` logs the first 16 buffer-owner failures with requested and owned ranges. Pass `-TraceCond50` only when investigating timed condition waits.

Warm shader caches are preserved. Recompiler changes still produce a new cache version on the next game run; standalone replay avoids that boot cost during iteration. These scripts set profiling environment variables in their PowerShell process; use a dedicated shell when invoking them manually.
